# Titanic Survival Analysis

## Project Overview
This project analyzes the Titanic dataset to understand passenger survival patterns using Python.

## Objectives
- Clean the Titanic dataset.
- Analyze survival by gender.
- Analyze survival by passenger class.
- Calculate survival rates by age group.
- Visualize passenger data.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Visualizations
- Survival Rate by Gender
- Survival Rate by Passenger Class
- Survival Rate by Age Group
- Passenger Age Distribution

## Dataset
Titanic dataset downloaded from Kaggle.

## Deliverable
Jupyter Notebook containing data cleaning, analysis, visualizations and insights.
